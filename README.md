# [ComfyUI_TUT_Nodes](https://github.com/3191312549/ComfyUI_TUT_Nodes)

面向持续扩展的 ComfyUI 自定义节点插件。本公开版提供文字排版与动画、几何文字、专业合成、电影调色、艺术滤镜、图片抠像、视频补帧、Excel 读取、文本与列表批次处理、图像对比、帮助查看和动画 GIF 保存，共 57 个正式节点。

## 安装

将整个 `ComfyUI_TUT_Nodes` 目录复制到：

```text
ComfyUI/custom_nodes/ComfyUI_TUT_Nodes
```

然后在 ComfyUI 的 Python 环境中安装文字塑形依赖：

```powershell
python -m pip install -r ComfyUI/custom_nodes/ComfyUI_TUT_Nodes/requirements.txt
```

`uharfbuzz` 用于复杂文字塑形；OpenCV 用于专业合成、透视、位移、形态学和电影调色；`openpyxl` 用于读取 `.xlsx` 和 `.xlsm`。插件不会在导入时自动安装依赖。

重启 ComfyUI。节点位于：

```text
TUT_Nodes → 图片 → 文本
TUT_Nodes → 图片 → 滤镜
TUT_Nodes → 图片 → 调色
TUT_Nodes → 图片 → 合成
TUT_Nodes → 图片 → 动画
TUT_Nodes → 图片 → 抠像
TUT_Nodes → 图片
TUT_Nodes → 视频 → 动画
TUT_Nodes → 工具 → Excel
TUT_Nodes → 工具 → 批次
```

节点界面的标题、参数、下拉选项、输入/输出端口、提示和错误，凡能准确使用中文表达的均显示为中文。为兼容已发布接口，工作流文件中的内部字段名和值仍可保持原有格式。

## 节点

- `TUT_叠加文字`：在 IMAGE 批次上绘制文字。
- `TUT_绘制文字`：生成带文字的纯色画布。
- `TUT_文字遮罩填充`：将输入图片填入文字区域。
- `TUT_文字图像合成`：按文字遮罩合成前景与背景。
- `TUT_文字水印`：批量添加定位水印。
- `TUT_自适应反色水印`：在四个角落添加随图片缩放的文字水印，通过文字遮罩逐像素显示底图反色。
- `TUT_选择字体`：选择插件字体或系统字体。
- `TUT_文字特效`：对 IMAGE + MASK 独立应用静态文字特效。
- `TUT_区域自适应文字`：按区域 MASK 的有效边界自动换行并寻找最大字号。
- `TUT_逐字逐词遮罩`：按字符、词或行输出独立 IMAGE/MASK 批次。
- `TUT_字体预览墙`：分页预览插件字体、系统字体或全部字体。
- `TUT_动态文字序列`：生成打字机、淡入、滑入、缩放弹入和扫光动画帧。
- `TUT_文字变形`：上/下拱、波浪、斜切、梯形和透视文字。
- `TUT_文字沿路径`：沿路径 MASK 的最长轮廓排列文字。
- `TUT_保存动画 GIF`：将 IMAGE 批次按顺序保存为动画 GIF，并输出实际保存的文件名。
- `TUT_GIMM-VFI补帧`：把 GIMM-VFI 模型加载与补帧合并为一个节点，复用已安装的 ComfyUI-GIMM-VFI 及其本地模型。
- `TUT_节点帮助`：将任意节点的任意输出连接进来，显示该节点的名称、说明、输入和输出文档。
- `TUT_文本分隔批次`：按自定义分隔符把一段文本拆成 STRING 列表，逐项驱动下游节点。
- `TUT_批次按编号加载`：接收完整的 ComfyUI 列表批次，使用从 0 开始的编号取出其中一个元素。
- `TUT_等待`：接收任意类型输入，等待设定的毫秒数后原样输出；每次执行都会实际等待。
- `TUT_读取Excel`：选择 `.xlsx`、`.xlsm` 文件、工作表、范围和公式模式，输出供其他 Excel 节点复用的表格数据。
- `TUT_Excel批次读取`：接收 Excel 数据，按行或按列把每组文本作为独立 STRING 列表项输出，并可限制读取组数。
- `TUT_Excel合并读取`：接收 Excel 数据，按行或按列使用自定义分隔符合并为单一 STRING，并可限制参与合并的组数。
- `TUT_Excel只读单行/单列`：按从 0 开始的编号读取指定行或列，同时输出逐单元格批次和合并文本。
- `TUT_图像对比`：叠加预览图像 A 与图像 B，图片上方以轻量文字标明左侧 A 和右侧 B，并通过无图标的滑动分割线检查差异。
- `TUT_LUT加载与预览`：上传或选择 `.cube`、`.3dl`、`.1dlut`、Hald/ReShade PNG，使用外接或手动上传图片滑动比较原图与 LUT 效果，并输出可复用 LUT 数据。
- `TUT_3D LUT调色`：接收加载节点的 LUT 数据或兼容旧工作流的文件路径，支持强度、MASK、批次、1D 线性插值和 3D 三线性插值。

LUT 上传文件保存在 ComfyUI 的 `input/TUT_Nodes/luts/`；也可把有权使用的 LUT 放入插件 `luts/`。LUT 数值按规范化 RGB 处理，不自动猜测或转换 Log、Rec.709、ACES 等色彩空间。

### 节点帮助

将任意节点的任意输出端口连接到 `TUT_节点帮助`，执行工作流后，帮助节点会在自身预览区域显示上游节点的使用文档，同时从 `help_document` 输出完整的 STRING 文本。

该节点通过工作流中的上游节点 ID 读取实际 `class_type`，因此不需要为每种 IMAGE、MASK、MODEL、LATENT 或 STRING 类型分别制作帮助节点。帮助内容包括节点名称、内部 ID、分类、执行函数、DESCRIPTION、输入字段、默认值和输出端口。

### Excel 读取

Excel 节点采用“加载一次、处理多次”的连接方式：先用 `TUT_读取Excel` 选择文件、工作表、读取范围和公式模式，再把“Excel数据”输出连接到 `TUT_Excel批次读取`、`TUT_Excel合并读取` 或 `TUT_Excel只读单行/单列`。右侧文件夹按钮打开 ComfyUI 所在电脑的本机文件选择器，直接记录工作簿绝对路径，不复制文件；下拉框同时兼容以前放在 `input/TUT_Nodes/excel/` 中的工作簿。工作表自动形成下拉选项，范围可选择“自动有效区”或填写自定义起止单元格，选择状态随工作流保存。

`TUT_Excel批次读取` 与 `TUT_Excel合并读取` 可在处理前忽略前 N 行或前 N 列，并设置读取数量上限。按行时上限控制行组数量，按列时控制列组数量；上限为 `0` 表示不限制。自动范围会裁去外围全空行列，内部空单元格仍会保留。

`TUT_Excel只读单行/单列` 使用从 `0` 开始的编号选择一行或一列，然后跳过前 N 个单元格并应用读取数量上限；上限为 `0` 表示不限制。它同时提供逐单元格批次和自定义分隔符合并文本，内部空单元格也会计入编号、跳过数量和读取上限。

文本组织支持 `\n`、`\t`、`\r` 分隔符转义。公式默认读取 Excel 上次保存的缓存值，也可切换为公式文本；插件不会计算或刷新公式。当前支持 `.xlsx`、`.xlsm`，不支持旧版 `.xls`、`.xlsb` 或加密工作簿。

此版本不再允许批次读取或合并读取节点直接打开文件，也不提供旧接口兜底。旧工作流需要手动加入 `TUT_读取Excel`，并将其“Excel数据”输出重新连接到原处理节点。

### 图片合成

`TUT_柔边图层合成` 将图一作为前景图层悬浮在图二上，只输出最终 `IMAGE`。支持位置、缩放、旋转、双轴透视、透明度和 normal/multiply/screen/overlay 混合模式；图二决定输出尺寸，可选 `layer_mask` 定义图一的任意轮廓。

边缘能力分为四个可组合模块：

- 形状：圆角、切角、波浪、撕裂。
- 消散：羽化、噪声溶解、像素崩解、墨水扩散。
- 材质：白边贴纸、纸张纤维、烧焦、玻璃切边。
- 光影：柔投影、斜面浮雕、霓虹边光、伪厚度。

提供自定义、自然悬浮、柔边照片、海报卡片、白边贴纸、撕纸拼贴、烧焦照片、玻璃面板、霓虹窗口、墨水渗透、像素崩解、噪声消散和厚卡片预设。预设只回填控件，之后仍可继续调整。`opacity=0`、全黑 MASK 或图层完全移出画布时会原样返回图二。

专业合成节点还包括：

- `TUT_光线包裹合成`：让背景亮光和颜色自然进入前景轮廓。
- `TUT_深度图合成`：根据两张深度图自动决定前后遮挡。
- `TUT_四角定位合成`：将前景精确映射到指定四边形。
- `TUT_通道布尔合成`：自由组合两张图的颜色与 Alpha 通道。
- `TUT_图像位移合成`：使用第二张图驱动 XY 位移。

### 电影调色

- `TUT_自动基础校色`：在指定区域内自动修正白平衡和曝光，排除极暗及过曝样本。
- `TUT_自动基础校色（高级）`：独立指定分析与应用区域，通过中性像素、多估计器融合和置信度自动减弱，提高单色场景下的稳健性，并输出实际取样遮罩与中文诊断报告。
- `TUT_基础明暗调整`：控制曝光、亮度、对比、高光、阴影、黑白场和光感。
- `TUT_基础色彩调整`：控制色温、色调、饱和度和自然饱和度。
- `TUT_图像细节增强`：控制降噪、去雾、清晰度、纹理、锐化、颗粒、褪色和暗角。
- `TUT_HSL基础调整`：按全局、红、橙、黄、绿、青、蓝、紫和洋红调整 HSL。
- `TUT_RGB曲线`：通过可视化编辑器调整 RGB 总曲线和红、绿、蓝单通道曲线。
- `TUT_双图颜色匹配`：将源图的亮度或颜色分布匹配到参考图。
- `TUT_电影色调塑形`：调整 Toe、Shoulder、密度、饱和度压缩和冷暖偏色。
- `TUT_卤化光晕`：从高光边缘生成红橙色胶片光晕。
- `TUT_镜头扩散`：模拟柔光镜、黑柔、薄雾和梦幻扩散。
- `TUT_色彩压缩器`：将离散色相向目标色域聚合，可保护亮度和肤色。

基础调色推荐串联顺序为“自动基础校色（普通或高级）→ 基础明暗调整 → 基础色彩调整 → 图像细节增强”，HSL 和 RGB 曲线按需追加。高级自动校色的 `analysis_mask` 只决定统计取样区域，`effect_mask` 只决定校正应用区域；低置信度会按阈值连续减弱白平衡。调色预设只负责回填控件，用户可以继续微调；后端始终使用最终参数。所有节点支持 optional MASK 和批次广播，零强度必须原样返回输入。

### 图片滤镜

- `TUT_复古印刷滤镜`：分色网点、套印偏移、油墨与纸张质感，附加输出 `ink_texture`。
- `TUT_漫画化滤镜`：色彩分层、线稿和阴影网点，附加输出 `line_mask`、`shadow_mask`。
- `TUT_万花筒滤镜`：2–24 扇区的确定性极坐标镜像。
- `TUT_像素艺术滤镜`：有限色板、Floyd/Bayer 抖动和像素描边，附加输出 `palette_image`。
- `TUT_玻璃折射滤镜`：波纹、条纹、磨砂、液态和水滴折射，附加输出 RG 位移图。
- `TUT_故障艺术滤镜`：RGB、VHS、数据块和像素排序故障，附加输出 `glitch_mask`。
- `TUT_动态滤镜序列`：生成色相、扫光、波纹、像素化、万花筒、故障和胶片闪烁动画。

滤镜统一支持可选 MASK 和 `strength`。单 MASK 可广播到多图；其他批次数量必须相等。`strength=0` 或全黑 MASK 会逐位保留原图。随机效果使用固定 `seed`，动态序列按“每张输入图的完整序列”输出，可直接连接 GIF 节点。

复古印刷、漫画、像素艺术、玻璃折射和故障艺术提供预设下拉框。预设只会回填控件，不锁定参数；回填后可继续微调，实际处理始终使用控件最终值。

### 图片抠像

三个抠像节点统一输出 `IMAGE, show_help, foreground_mask, background_mask`。`foreground_mask` 是前景遮罩，`background_mask` 始终为其反相；透明区域在 RGB `IMAGE` 中以黑色表示，可继续使用遮罩完成后续合成。

- `TUT_颜色抠像`（`TUT_ColorKeying`）：使用 Lab 感知色差进行绿幕、蓝幕、白底、黑底或自定义颜色抠像，并支持颜色容差和溢色抑制。
- `TUT_AI智能抠像`（`TUT_AIKeying`）：通过可选的 `rembg` 运行依赖自动识别前景。模型按需下载并按模型、设备缓存；插件导入和自动测试不会联网。
- `TUT_SAM遮罩抠像`（`TUT_SAMMaskKeying`）：接收外部 SAM1、SAM2、SAM2.1、SAM3 或其他分割节点生成的 `MASK`，不直接加载或绑定特定 SAM 插件。
- `TUT_差异抠像`：比较当前图与干净背景图生成前景 MASK 和差异图。
- `TUT_遮罩边缘精修`：清理黑白场、孔洞、边缘细节和背景色污染。

三个节点均支持前景遮罩扩张/收缩、边缘羽化和反转。IMAGE 与 MASK 批次仅允许等长或单批次广播。

### GIF 压缩

`TUT_保存动画 GIF` 提供以下压缩预设。选择预设后会自动回填压缩参数，仍可继续手动调整：

- `自定义`：不回填参数，完全使用当前设置。
- `高画质`：缩放 0.85、256 色、不跳帧、开启抖动和优化。
- `均衡`：缩放 0.75、128 色、不跳帧、关闭抖动、开启优化。
- `小体积`：缩放 0.5、64 色、每 2 帧取 1 帧、关闭抖动、开启优化。

手动参数包括 `resize_scale`、`max_colors`、`frame_step` 和 `dither`。`max_colors` 使用 2、4、8、16、32、64、128、256 色档位切换。跳帧压缩会同步延长保留帧的显示时间，保持动画总播放时长不变。体积优先时建议从“均衡”开始，如果仍然过大再选择“小体积”。

`保存元数据` 默认开启，将提示词和工作流写入 GIF comment；关闭后不写入任何 metadata。

图像文字节点会同时输出处理后的 `IMAGE` 和原始文字 `MASK`。MASK 可以连接到 `TUT_文字特效`，也可以连接其他 ComfyUI 遮罩节点。

## 静态特效

`effect_preset` 提供以下预设：

- `none`：基础文字。
- `custom`：完全使用手动参数。
- `outline`：描边。
- `shadow`：投影。
- `glow`：外发光。
- `neon`：霓虹描边与发光。
- `gradient`：渐变填充。
- `emboss`：浮雕。
- `extrude`：立体挤出。

还可以调整线性/径向渐变、透明度、两层外描边、描边间距、内描边、高光、发光半径、阴影偏移、浮雕深度、挤出方向和混合模式。新增参数默认关闭，因此旧工作流的默认结果不变。

## 批次与动画顺序

- 逐字逐词遮罩：先按输入图片，再按文字单位展开，即 `B × units`。
- 动态文字与动态滤镜：先按输入图片，再按帧展开，即 `B × frames`。
- 动态节点不管理 FPS；用 `TUT_保存动画 GIF` 设置播放速度。
- 无缝循环按周期相位采样，不重复首帧；随机动画复用固定噪声场。

## 字体

插件会扫描系统字体，并支持插件自带字体目录：

```text
ComfyUI_TUT_Nodes/fonts
```

将 `.ttf`、`.otf` 或 `.ttc` 文件放入该目录后重启 ComfyUI。插件字体以 `builtin/` 开头，系统字体以 `system/` 开头。

字体预览墙会优先显示字体文件内记录的真实家族名和样式名。完整文本通过 HarfBuzz 塑形和栅格化；逐字、逐词动画仍按所选拆分单位输出，以保持旧工作流的帧数和端口语义。

## 扩展分类

分类名称集中在 `categories.py`，节点注册集中在 `registry.py`。当前预留：

```text
TUT_Nodes/图片
TUT_Nodes/图片/文本
TUT_Nodes/图片/滤镜
TUT_Nodes/图片/调色
TUT_Nodes/图片/合成
TUT_Nodes/图片/动画
TUT_Nodes/图片/抠像
TUT_Nodes/视频/动画
TUT_Nodes/工具/文件
TUT_Nodes/工具/文本
TUT_Nodes/工具/Excel
TUT_Nodes/工具/批次
```

新增节点组时，在相应的 `nodes/<大类>/` 模块中定义映射，并在 `registry.py` 中合并即可。
